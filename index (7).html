🎯 سایت شما آمادهٔ انتشار است

ابتدا فایل را دانلود کنید، سپس با یکی از روش‌های زیر آن را روی هاست/سرور قرار دهید تا سایت زنده شود.

⬇️ دانلود فایل index.html 🚀 انتشار آنی رایگان (Netlify Drop)

۱) دانلود فایل

دکمهٔ بالا فایل index.html را روی کامپیوتر شما ذخیره می‌کند. اگر روی موبایل هستید، فایل را در پوشهٔ Downloads نگه دارید و بعداً با گوشی به هاست منتقل کنید.

نکته: پسوند فایل حتماً باید .html باشد (نه .html.txt). برای ویرایش، فایل را با Notepad++ / VS Code باز کنید.

۲) رایگان‌ترین و سریع‌ترین روش: Netlify Drop

  1. روی دکمهٔ سبز بالا کلیک کنید (یا به app.netlify.com/drop بروید).
  2. فایل index.html را بکشید و داخل کادر رها کنید (Drag & Drop).
  3. چند ثانیه صبر کنید؛ آدرسی مثل https://your-site-name.netlify.app به شما داده می‌شود.
  4. همین آدرس، آدرس سایت شماست و رایگان است. می‌توانید دامنهٔ دلخواه را بعداً وصل کنید.

مزیت: بدون کارت بانکی، بدون تنظیمات فنی، SSL رایگان. مناسب تست و سایت‌های کوچک.

۳) روش دوم: GitHub Pages (رایگان)

  1. در GitHub یک مخزن (Repository) جدید بسازید و آن را Public کنید.
  2. فایل index.html را در ریشهٔ مخزن آپلود کنید (دکمهٔ Add file → Upload files).
  3. به مسیر Settings → Pages بروید، Source را روی main / (root) بگذارید و Save کنید.
  4. پس از ۱ تا ۳ دقیقه سایت روی https://username.github.io/repo/ بالا می‌آید.

۴) روش سوم: هاست اشتراکی (cPanel / FTP) — سایت اصلی

  1. از شرکت هاستینگ، اطلاعات FTP یا کنترل‌پنل cPanel را بگیرید (Host / Username / Password / Port).
  2. فایل index.html را با FileZilla به مسیر public_html/ آپلود کنید.
  3. دامنه را در بخش Domains پنل به هاست وصل کنید (اگر دامنه دارید).
  4. دکمهٔ «تست/آزمایش» یا «Publish» را بزنید تا سایت منتشر شود. گاهی ۵ تا ۱۵ دقیقه طول می‌کشد.
Host: ftp.yourhost.com
User: your-username
Pass: your-password
Port: 21
Remote path: /public_html/index.html

۵) روش چهارم: سرور اختصاصی / VPS (لینوکس)

  1. فایل را با scp یا WinSCP روی سرور کپی کنید:
scp index.html user@your-server-ip:/var/www/html/
  1. وب‌سرور Nginx را نصب و فایل را به ریشهٔ سایت بسپارید:
sudo apt update && sudo apt install -y nginx
sudo cp index.html /var/www/html/index.html
sudo systemctl enable --now nginx
  1. فایل تنظیمات سایت را بسازید:
sudo nano /etc/nginx/sites-available/mysite
---
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    root /var/www/html;
    index index.html;
    location / { try_files $uri $uri/ =404; }
}
---
sudo ln -s /etc/nginx/sites-available/mysite /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
  1. برای SSL رایگان از Certbot استفاده کنید:
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com -d www.your-domain.com
  1. پورت ۸۰ و ۴۴۳ را در فایروال باز کنید تا سایت از بیرون دیده شود.

۶) کدام روش برای من مناسب است؟

نیاز شماپیشنهادهزینه
فقط تست سریع / نمونه‌کارNetlify Drop یا GitHub Pagesرایگان
سایت فارسی با دامنهٔ شخصیهاست اشتراکی cPanelماهانه
کنترل کامل و سرعت بالاVPS + Nginxماهانه

هر سه روش نهایتاً یک فایل HTML روی سرور قرار می‌دهند؛ تفاوت فقط در ابزار و میزبانی است.

۷) چک‌لیست نهایی

  • نام فایل دقیقاً index.html باشد و در ریشهٔ پوشهٔ سایت قرار بگیرد.
  • حروف بزرگ/کوچک نام فایل مهم است (Index.html روی بعضی سرورها کار نمی‌کند).
  • اگر فایل‌های دیگری (CSS/JS/تصویر) دارید، آن‌ها را هم آپلود کنید و مسیرها را بررسی کنید.
  • پس از آپلود، چند دقیقه صبر کنید و سپس آدرس دامنه را باز کنید.
  • در صورت خطای ۴۰۴: فایل در مسیر درست نیست یا نامش اشتباه است.
ساخته‌شده برای انتشار سریع سایت شما — همین فایل، همان چیزی است که باید روی هاست قرار بگیرد.
